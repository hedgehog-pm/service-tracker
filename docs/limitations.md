# Ограничения

## Участники и доступ

1. Исполнители, авторы, комментарии, вложения и уведомления пока не поддерживаются.
2. В HTTP API нет встроенной авторизации и разграничения прав по проектам.
   Создание отдельного проекта не ограничивает доступ к нему для других пользователей.

## Задачи и процессы

1. Связей между задачами и подзадач нет. Тип `Epic` не объединяет другие задачи.
2. Спринты и учёт фактически затраченного времени пока не поддерживаются.
3. После создания нельзя изменить тип задачи, перенести её в другой проект
   или назначить модуль другого проекта.
4. Создание и изменение справочников типов задач, статусов, переходов и приоритетов
   через API не поддерживаются. Настроить правила выполнения задач через API тоже нельзя.
5. Частичного обновления через `PATCH` нет. `PUT` заменяет редактируемые поля целиком.

## Поиск

1. Общего списка задач разных проектов нет. Выборка доступна только в пределах одного проекта.
2. [Фильтры](guides/tasks.md#find-tasks) принимают по одному идентификатору
   статуса, модуля, типа задачи или приоритета.
3. Полнотекстового поиска, фильтра по сроку и отдельной выборки задач без модуля пока нет.

## Удаление и история

1. Архива и корзины нет. Восстановить удалённые данные через API нельзя.
2. История изменений через API недоступна.
