# Ограничения

## Участники и доступ

1. Исполнители и авторы задач, комментарии к задачам, вложения и уведомления пока не поддерживаются.
2. В HTTP API нет встроенной авторизации и разграничения прав по проектам.
   Поэтому создание отдельного проекта не ограничивает доступ к нему для других пользователей.

## Задачи и процессы

1. Связей между задачами и подзадач нет, поэтому тип `Epic` не объединяет другие задачи.
2. Спринты пока не поддерживаются.
3. После создания нельзя изменить тип задачи, перенести её в другой проект
   или назначить модуль другого проекта.
4. Через API нельзя создавать и изменять справочники типов задач, статусов, переходов и приоритетов
   или настраивать правила выполнения задач.
5. Частичного обновления через `PATCH` нет. `PUT` заменяет редактируемые поля целиком.

## Доски

1. Доска показывает задачи только своего проекта.
2. В колонки попадают задачи по статусам. Дополнительно отобрать их по модулю,
   типу задачи или приоритету пока нельзя.
3. Независимый порядок задач для каждой доски не поддерживается.
4. Управление общими схемами досок через API пока недоступно.

## Поиск

1. Получить список задач можно только в пределах одного проекта.
2. [Фильтры](guides/tasks.md#find-tasks) принимают по одному идентификатору
   статуса, модуля, типа задачи или приоритета.
3. Полнотекстового поиска, фильтра по сроку и отдельной выборки задач без модуля пока нет.

## Удаление и история

1. Архива и корзины нет, поэтому восстановить удалённые данные через API нельзя.
2. История изменений через API недоступна.
