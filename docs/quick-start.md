# Создать первую задачу

Создайте проект Веб-витрина, добавьте задачу и переведите её в работу.

## Создайте проект

```sh title="POST /projects"
curl http://localhost:8080/projects --json '{
  "key": "WEB",
  "name": "Веб-витрина"
}'
```

Сервис вернёт `201 Created` и созданный проект.

```json title="Пример ответа · 201 Created"
{
  "id": 1,
  "key": "WEB",
  "name": "Веб-витрина"
}
```

## Выберите тип задачи

```sh title="GET /projects/1/task-types"
curl http://localhost:8080/projects/1/task-types
```

В списке `items` выберите тип `Task`.
В поле `initial_status` указан статус, который получит новая задача.

## Создайте задачу

```sh title="POST /projects/1/tasks"
curl http://localhost:8080/projects/1/tasks --json '{
  "title": "Добавить фильтр по цене",
  "task_type_id": 1
}'
```

Сервис вернёт `201 Created` и созданную задачу.
Проверьте её `key`, `task_type_id`, `status_id` и `priority_id`.
В новом стандартном проекте первая задача получит ключ `WEB-1`,
начальный статус `Open` и приоритет `Medium`.

## Узнайте доступные действия

```sh title="GET /projects/1/tasks/1/transitions"
curl http://localhost:8080/projects/1/tasks/1/transitions
```

В списке `items` находятся переходы, доступные задаче сейчас.
У каждого перехода есть `id`, название `name` и целевой статус `to`.
В стандартном процессе для новой задачи доступно действие `Start progress`.

В поле `transition_id` следующего запроса укажите `id` действия `Start progress`.
Поле `to.id` содержит идентификатор целевого статуса и для этой операции не подходит.

## Переведите задачу в работу

```sh title="POST /projects/1/tasks/1/transitions"
curl http://localhost:8080/projects/1/tasks/1/transitions --json '{
  "transition_id": 1
}'
```

Сервис вернёт `200 OK` и задачу с новым `status_id`.
Он должен совпасть с `to.id` выбранного перехода.
В стандартном процессе задача окажется в статусе `In Progress`.

Чтобы завершить задачу, снова получите доступные переходы
и выполните `Complete` с идентификатором из нового ответа.
Если переход вернул `409 Conflict`, статус задачи мог измениться после предыдущего запроса.
Получите доступные действия заново и выберите переход для текущего статуса.

## Проверьте результат

```sh title="GET /projects/1/tasks/1"
curl http://localhost:8080/projects/1/tasks/1
```

Убедитесь, что ответ содержит созданную задачу и ожидаемый статус.
