# О сервисе

В сервисе можно создать проект, завести в нём задачи и следить за их выполнением.
Для каждой задачи выбирают тип и приоритет.
При необходимости указывают срок и оценку трудозатрат.

Внутри проекта задачи можно распределить по модулям.
Например, задачи каталога и оплаты будут относиться к разным модулям.

Статус задачи меняется по правилам её процесса выполнения.
В стандартном процессе задачу берут в работу, завершают или возвращают в начальный статус.
Для работы с проектами и задачами сервис предоставляет HTTP API.

*Схема прохождения задачи от создания в проекте до завершения.*
