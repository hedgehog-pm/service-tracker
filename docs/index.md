# О сервисе

Через HTTP API сервиса можно создать проект, завести в нём задачи и следить за их выполнением.
Для каждой задачи выбирают тип и приоритет,
а при необходимости указывают срок и оценку трудозатрат.

Внутри проекта задачи можно распределить по модулям.
Например, задачи каталога и оплаты будут относиться к разным модулям.

Те же задачи можно показать на доске, где они сгруппированы по статусам.
Чтобы перемещать их между колонками, выполняют переходы по правилам процесса.
В стандартном процессе задачу берут в работу, завершают или возвращают в начальный статус.
Под этот процесс можно настроить колонки, а внутри них расставить задачи вручную.
