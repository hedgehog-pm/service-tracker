# service-tracker

Сервис для ведения проектов и задач. Задачи можно распределять по модулям,
задавать им приоритеты и сроки, менять статусы по правилам проекта.

## Документация

Для локального просмотра нужен Python 3. Запустите документацию из корня сервиса:

```sh
make docs
```

Документация будет доступна по адресу [localhost:8000](http://127.0.0.1:8000).
